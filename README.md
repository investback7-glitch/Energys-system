# Energy Revolution Landing Page

Static affiliate landing page for GitHub Pages / Netlify / Vercel.

## Before publishing
1. Replace `https://YOUR-DOMAIN.com/` in `index.html` with your real domain.
2. The CTA already uses the supplied ClickBank HopLink.
3. If you have approved product images, replace the CSS hero illustration with those assets.
4. Do not add fabricated testimonials or claims of personal testing.
5. Confirm the current price, bonuses and refund terms on the live checkout before advertising.

## Deploy
Upload `index.html` to the root of your GitHub repository. GitHub Pages can serve it directly.
